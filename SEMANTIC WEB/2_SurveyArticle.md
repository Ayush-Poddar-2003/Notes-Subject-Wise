# Jorge Cardoso Survey

2003 Survey: “Semantic Web: Vision, Challenges, and Applications.”

Highlights:
- Potential of Semantic Web for knowledge management.
- Issues in adoption: lack of standards, tooling, and semantic content.
- Emphasizes ontologies, RDF, and reasoning engines as core enablers.

# Scientific American Article 2001

Title: “The Semantic Web” by Tim Berners-Lee, James Hendler, Ora Lassila.

Key Points:
- Web 2.0 content is human-readable but not machine-understandable.
- Semantic Web will allow computers to interpret meaning, integrate, and reason.
- Predicts intelligent agents assisting in tasks like research, e-commerce, and personalized services.
