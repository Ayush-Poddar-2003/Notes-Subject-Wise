
Sir Tim Berners-Lee is a British computer scientist and the inventor of the World Wide Web (WWW).  
He proposed the web in 1989 while working at CERN to enable easy information sharing among scientists.

Visions :- 
- Universal access to information
- Decentralized web
- Open and royalty-free standards
- Semantic Web (machine-understandable data)
- User data ownership, privacy, and trust

Contributions :- 
- Invention of the World Wide Web
- Development of HTML
- Development of HTTP
- Introduction of URL
- First web browser and web server
- Founding of World Wide Web Consortium (W3C)
- Semantic Web initiative
- Global recognition and awards
