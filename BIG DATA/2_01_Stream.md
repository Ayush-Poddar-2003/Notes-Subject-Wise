# DATA STREAM ?  
Continuous, rapid, time-varying sequence of data generated by sources such as sensors, online transactions, social media, network traffic, or IoT devices.

Characteristics
- Continuous and unbounded (no limit to incoming data)
- High velocity (arrives very fast)
- Order matters (time-based arrival)
- Limited storage (cannot save all data)
- Real-time processing needed

STREAMING ?  
Continuous, never ending data stream with no beginning or end.

TYPES ?  
1. TRANSACTIONAL  
B/W 2 different entities

2. MEASUREMENT DATA STREAM ?  
They carry data related to measured value

---

DATA STREAM QUERIES ?  
1. Adhoc Queries  
we make a query once and expect an answer to the query based on the current state of the system

2. Standing Queries  
the users expect the system to report the answer available at all times
