### Data Quality: Why Preprocess the Data?

Raw data is often:
- Incomplete (missing values)
- Noisy (errors/outliers)
- Inconsistent (conflicts)
- Redundant (duplicate data)
- Heterogeneous (different formats)


**DATA PREPROCESSING ?**  
Set of techniques used to clean, transform, and prepare raw data before applying data mining algorithms.

MAJOR TASKS :-
1. Data Cleaning
2. **Data Integration**   
Combining data from multiple sources into a single consistent view
3. **Data Reduction**  
Reducing the volume of data while keeping its meaning intact.
4. **Data Transformation**  
Converting data into a suitable format for mining.  
5. **Data Discretization**  
Converting continuous data into discrete classes.
