# Getting to Know Your Data

### Data Objects ?
A data object (record, instance, sample, or tuple)  
represents a real-world entity.  
Each data object has a set of attributes.

---
### Attribute (Feature) ?
An attribute is a property/characteristic of a data object.  


### <center> Types of Attributes

**1. Nominal Attributes -**  
Categories with no order  
Examples: Gender (Male/Female)

**2. Binary Attributes -**  
Values: 0 or 1, True/False

**2.1 Symmetric binary**:  
Both values are equally important.  
Examples: Gender, Yes/No, True/False.

**2.2 Asymmetric binary**:  
One value is more important, usually the "positive" case.  
Examples: Fraud (Yes/No), Medical test (Positive/Negative).

**3. Ordinal Attributes**  
Values have a meaningful order or ranking.    
But the difference between the ranks is unknown.  
Examples:
Grades (A, B, C), Shirt sizes (S, M, L, XL), 

**4. Numeric Attributes**  
Numeric values

**5.1 Discrete Attributes**:-  
Finite or countable values, 
Usually integers.  
Examples:
Number of subscribers, number of likes.

**5.2 Continuous Attributes**:-  
Can take any real value within a range.  
Usually measurements.  
Examples:
Height, weight, temperature.

---
Nominal: No order; labels only.  
Binary: Two values; can be symmetric or asymmetric.  
Ordinal: Ordered categories; differences not measured.   
Numeric: Real numbers; can be discrete or continuous.
