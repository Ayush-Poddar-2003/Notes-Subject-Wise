## 5. Evaluating Schedule Risk Using PERT
`TE = (O + 4M + P) / 6`  
`Variance = ((P – O) / 6)²`

Used to determine reliable project timelines.

---

---

## 7. Earned Value Analysis (EVA)
### Terms:
- **PV** – Planned Value  
- **EV** – Earned Value  
- **AC** – Actual Cost  

### Indices:
- **CPI = EV / AC**  
- **SPI = EV / PV**  

> CPI < 1 → Over budget  
> SPI < 1 → Behind schedule
