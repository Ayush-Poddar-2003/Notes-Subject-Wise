# Context Awareness and Management
Context = any information that characterizes the situation of:
- A user
- A device
- An environment

Examples:
Location, time, activity, device status, temperature, network condition.

# Context Management Framework
1. Context Acquisition Layer
2. Context Modeling Layer
3. Context Storage Layer
4. Context Reasoning Layer
5. Context Distribution Layer
6. Application Layer
