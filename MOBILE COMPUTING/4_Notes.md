# Service Discovery
Process of automatically finding services available in a network with minimal user involvement.  
Enable mobile devices to discover, access, and use services efficiently in a changing environment.

### Classifications of Service Discovery Frameworks
1. Directory-Based vs. Non-Directory-Based
2. Pull-Based vs. Push-Based
3. Network-Based vs. Application-Level
4. Centralized vs. Distributed Approaches
5. Reactive vs. Proactive Discovery

### Considerations for Service Discovery
1. Mobility
2. Limited Resources
3. Network Constraints
4. Scalability
5. Security
6. Interoperability
7. Context Awareness

# Mobile Agents
Programs that can move across networks autonomously to perform tasks.  
Agents provide: Information retrieval, Task automation, Resource monitoring, Communication between nodes, Dynamic service negotiation

# Introduction to Mobile OS

#### 1. Android
- Open-source (Linux kernel-based)
- Developed by Google.
- Uses Java/Kotlin for app development.
- Huge ecosystem and market share.

#### 2. iOS
- Developed by Apple.
- Closed-source, highly secure.
- Apps built using Swift or Objective-C.

#### 3. Embedded Linux
- Lightweight Linux versions for embedded/mobile devices.
- Used in smart devices, POS machines, wearables.

#### 4. Windows Mobile / Windows Phone
- Old Microsoft mobile OS (now discontinued).
- Apps built using C#, .NET.

#  Application Development Languages

### 1. HTML5
- Used for hybrid apps (via Cordova, PhoneGap).
- Cross-platform.
- Supports offline storage, multimedia, responsive UI.

### 2. Java 2 ME (Latest Version)
- Lightweight Java platform designed for mobile and embedded devices.
- Used in feature phones, sensors, IoT devices.
- Provides CLDC (Connected Limited Device Configuration) and MIDP (Mobile Information Device Profile).

### 3. BREW (Binary Runtime Environment for Wireless)
- Developed by Qualcomm.
- Used for native mobile apps on CDMA devices.
- Fast performance, C/C++ programming.
- Provided good hardware control but now rarely used.
