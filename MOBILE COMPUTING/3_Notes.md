# SOA

### Why SOA/SOC for Mobile Services?

SOA = architectural model where services are:
- Loosely coupled
- Discoverable
- Interoperable
- Reusable

### Why SOA is ideal for mobile services ?
1. Heterogeneous Mobile Environments
2. Dynamic and Mobile Nature
3. Resource Constraints
4. Scalability
5. Interoperability
6. Reusability of Services
7. Security and Manageability

---
### Architectural Styles for Mobile Web Services
1. SOAP-Based Web Services
2. RESTful Web Services
3. Microservices Architecture
4. Event-Driven Architecture
5. Client-Server Architecture

### Protocols for Mobile Web Services
1. SOAP Protocol
2. REST Protocol
3. XML-RPC / JSON-RPC
4. MQTT (Message Queuing Telemetry Transport)
5. WAP/WSP (Wireless Protocol Suite)
6. WebSocket Protocol
